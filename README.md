# 🐾 MeowShop | Ruled by Cats, Loved by Humans

A sleek, responsive, and witty e-commerce landing page concept built from scratch using pure HTML5 and CSS3. 

![MeowShop Demo](./imgs/web.gif)

---

## ✨ Overview
**MeowShop** delivers a high-end, humorous shopping experience curated exclusively for feline royalty. The project focuses on clean design architecture, accessible layouts, and seamless user interaction without relying on heavy external UI frameworks.

---

## 🚀 Features
- **Hero Section:** High-impact visual overlay with prominent Call-to-Action (CTA).
- **Product Showcase:** Clean card grid presenting curated cat essentials (litter, dry food recipes, and pricing tiers).
- **Responsive Layout:** Adaptive Flexbox structure designed for consistent presentation across screen sizes.
- **Interactive Form:** Styled contact section with active focus states and locked vertical textarea sizing for optimal UX.
- **Modern Typography:** Custom typography pairings using Google Fonts (`Poppins` & `Pacifico`).

---

## 🛠️ Built With
- **HTML5:** Semantic and accessible page structure.
- **CSS3:** Custom properties (Variables), Flexbox, smooth scrolling, and micro-animations.

---

## 💻 Getting Started Locally

1. Clone the repository:
```Bash
   git clone [https://github.com/](https://github.com/SH-AHD/meowshop-landing-page)
```
2. Navigate to the project directory:
```Bash
    cd meowshop-landing-page
```
3. Open `index.html` in your favorite web browser (or use VS Code Live Server).
